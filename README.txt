Ludo Best — Dark Navy Blue UI Starter

Files:
- index.html: Responsive frontend and interactions
- assets/ludo-hero.png: illustration cropped from your supplied reference video
- assets/ludo-match-banner.png: match banner cropped from your supplied reference video

How to run:
1. Extract the ZIP.
2. Open index.html in a browser, or upload the files to GitHub Pages.
3. Keep the assets folder beside index.html.

Working in this frontend prototype:
- Home / Refer / Profile navigation
- Games / Others tabs
- Play Now opens game mode choices
- Ludo Matches opens match list and category filters
- Join buttons, demo wallet balance, profile name saving
- Referral code copy and WhatsApp sharing
- Profile menus, statements, notification screen
- Last opened screen is saved on the same device

Important:
This is a front-end prototype. Demo wallet amounts are local to the device and are not real money.
Real authentication, multiplayer matchmaking, deposits, withdrawals, Telegram invite URL, and live account data
need a secure backend and configured official URLs before production use.
