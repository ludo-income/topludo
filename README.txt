TopLudo UI Build v1

Implemented in this standalone ZIP:
- Screenshot-inspired dark/blue/cyan/yellow mobile UI
- Home / Games / Others tabs
- Play Now -> Ludo Matches
- Match list with serial numbers
- Auto/Open/Close status based on 0/1/2 local players
- Join button
- Ludo King room-code display after second player
- Copy room code
- Telegram action
- Wallet/balance UI
- Withdrawal UI shell
- Refer page
- Profile page
- Local admin panel for adding matches and room codes
- Browser localStorage persistence
- All visible buttons are wired to a working UI action

Important:
This ZIP is a standalone frontend build. It cannot provide real multi-device accounts, real-time multiplayer state, production push notifications, or real payment processing without a backend/database and service credentials. Those are intentionally not faked.
